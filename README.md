# Keymapper Vector Tiles

This repository hosts vector tiles for the Keymapper application.

## Tile Structure
- `LAD_tiles/` - Local Authority District boundaries
- `MSOA_tiles/` - Middle Super Output Area boundaries  
- `LSOA_tiles/` - Lower Super Output Area boundaries

## Usage
Base URL: `https://yourusername.github.io/keymapper-tiles/`

Tile URL pattern: `{base_url}/{type}_tiles/{z}/{x}/{y}.pbf`

## File Size
Total size: ~400MB
